# RIFT — Pixel Royale

A mobile-first 2D top-down pixel battle-royale project.

## v0.1
- 2D pixel-style island
- WASD + mobile joystick movement
- Camera following
- Water and POIs
- Trees and rocks
- Pickaxe harvesting
- Health/shield HUD
- Material counters
- GitHub Pages ready

## Roadmap
v0.2 — harvesting polish + inventory
v0.3 — building + editing
v0.4 — weapons + loot + chests
v0.5 — storm + bots + Battle Bus
v1.0 — full battle royale
